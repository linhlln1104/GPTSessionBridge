Tool-capable Web Agent

Reading tool access status…

This experimental mode exposes Web Agent models only while this tab is connected and its consent lease is active. Availability also depends on the visible ChatGPT model picker.

Activating this experimental mode allows GPTSessionBridge to write:

  • your coding request, developer context, and source excerpts;
  • tool names, definitions, and input schemas;
  • tool arguments; and
  • tool results.

This data is written into the visible ChatGPT conversation and may be retained according to your ChatGPT account and history settings. Developer-role priority is not preserved in the Web composer.
